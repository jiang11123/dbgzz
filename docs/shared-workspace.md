# 工作站使用说明

## 多账号

顶部账号栏点击切换账号，每个账号拥有独立的浏览器 Session（`persist:doubao_XX`），互不影响登录状态。

- 添加账号：顶部「添加账号」，可选择豆包（国内版）或 Dola（国际版）。
- 账号设置：右上角「设置」→ 账号管理，可改名、加备注、拖动排序、设置快捷键、删除。
- 快捷键：设置页可为每个账号绑定一个快捷键，在主窗口按下即可切到该账号。
- 启动时会错峰预热所有账号页面，切换时无需重新加载。

## 图片资产

顶部「图片资产」打开资产库。导入的图片按内容 SHA256 去重，原文件删除后仍可继续使用。

- 顶部图片栏是快捷预览区，可勾选、排序、拖拽到豆包输入框。
- 资产库内可多选后直接添加到当前账号的输入框（通过 CDP 注入文件，不弹系统选择框）。
- 聊天中的可读取大图会保存为图片资产；网页只提供预览图时不保证原始分辨率。

## 跨账号发送

在豆包输入框输入消息并添加图片后，**右键发送按钮**：

- 「发送到此账号」：把文字和图片发到目标账号并直接发出。
- 「同步到此账号」：只准备到目标账号输入框，检查后手动发送。

目标账号已有草稿时停止，保留原草稿；发送成功后只清理来源中未改变的文字。
左键和回车保持豆包原生行为。

## 按顺序重新导入聊天图片

右键发送按钮，选择目标账号下的「读取聊天图片，按顺序重新导入…」。预览窗口可读取来源输入框、最近含图消息或已加载的聊天图片，编号代表导入顺序，可前移、后移或移除。点击「按顺序重新导入到输入框」后，工作站逐张重新上传，确认当前图片出现后才处理下一张。

某张图片不能读取或上传时报告失败，不发送文字。

## 视频下载

- 网页内触发的下载会被拦截并保存到「下载监听目录」，文件名加时间戳前缀，不覆盖已有文件。
- 重复下载会弹窗确认；同一任务中不同视频可能使用相同文件名。
- 在豆包视频上**右键**可选择下载无水印原视频（走分享接口解析）。
- 豆包分享链接可在工作站内解析并保存。

## 本地画布桥接

工作站内置本地 HTTP 服务 `http://127.0.0.1:3219`，仅监听本机：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 服务状态、排队任务数、账号池健康度 |
| GET | `/accounts` | 账号列表与忙闲状态 |
| POST | `/tasks` | 创建视频生成任务（自动分配账号） |
| GET | `/tasks/{id}` | 查询任务状态与视频地址 |
| GET | `/tasks/{id}/video` | 下载任务视频 |
| GET | `/tasks/{id}/screenshot` | 截取执行账号页面 |
| POST | `/tasks/{id}/cancel` | 取消任务 |

## 账号池调度

任务按账号池状态自动分配，不再依赖账号名：

- **healthy**：可调度。
- **cooling**：临时失败（网络、限流），按指数退避冷却 30 秒 ~ 10 分钟，到期自动恢复。
- **quota_exhausted**：当日额度用尽，次日 0 点自动恢复。
- **captcha**：触发人机验证（`710022004`），需人工在豆包窗口处理，不会自动恢复。
- **logged_out**：登录态失效，需重新登录。

调度在可用账号间按权重随机；验证码与掉线账号永不被选中。池状态持久化在用户数据目录的 `account-pool.json`。

## 本地数据

Electron 用户数据目录内：

- `workspace-data/workspace.db`：账号、项目、任务、视频库记录。
- `image-assets`：图片资产副本。
- `account-pool.json`：账号池健康度与冷却状态。
- `canvas-bridge-tasks.json`：画布桥接任务。

## 验证

`npm run typecheck`、`npm test`、`npm run build`。

`electron scripts/check-account-send.cjs` 覆盖跨账号文字/图片发送、只同步草稿、目标草稿保护。
`electron scripts/check-no-duration.cjs` 覆盖旧库迁移与账号池调度。
测试不消耗真实账号额度；真实网页仍需要实际使用验证。
