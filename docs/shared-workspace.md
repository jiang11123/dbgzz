# 共享工作区

重启工作站后，顶部“共享聊天”用于管理记录和共同记忆。

## 主副账号

打开“共享聊天”→“主副账号”，填写分组名称、主账号和副账号后保存。
同一分组的账号可以使用共享会话。支持多个分组，点击分组可以编辑。
工作站启动时优先打开第一个分组的主账号；未配置分组时仍打开第一个账号。

## 共享聊天与记忆

1. 选择分组并创建共享聊天。
2. 编辑共同记忆，勾选图片资产，点击“保存记忆与图片”。记忆可以修改或清空。
3. 在豆包打开聊天，滚动加载需要的历史记录，点击“保存当前聊天进度”。
4. 切换账号后，点击“预览接续内容”，或“接着聊到当前账号”。
5. 返回豆包检查文字和图片，手动发送。

当前共享会话会在切换账号时尝试保存已加载记录；无法识别的页面需要使用手动保存检查结果。
工作站保留每次不同的记录快照、账号来源和页面地址。接续使用共同记忆及各页面最新快照中的近期原文。
聊天中的可读取大图会保存为图片资产。网页只提供预览图时不能保证获得原始分辨率；原图应从资产库关联。
不会覆盖输入框已有草稿，也不会在视频模式下把聊天背景作为生成任务发送。

## 右键同步聊天消息

1. 在豆包聊天框输入消息，可添加图片。
2. 右键发送按钮，选择其他账号；不要求先建分组。
3. “发送到此账号聊天框”将文字和图片发送到目标账号的普通聊天。
4. “只同步到此账号输入框”准备内容，检查后手动发送。

目标账号已有草稿时停止，保留原草稿。发送成功后仅清理来源中未改变的文字；只同步草稿时保留来源文字。
左键和回车保持豆包原生行为。工作站不再提供视频代发、模型/时长选择、视频任务和结果回传。

## 本地数据

Electron 用户数据目录内：

- `shared-chats.json`：主副账号分组、共享记录、记忆及图片关联。
- `image-assets`：保存的图片副本。

既有账号、聊天记录、图片资产和已保存视频不会随功能移除而删除。

## 验证

`npm run typecheck`、`npm run build`。

`electron scripts/check-collaboration.cjs` 覆盖分组、聊天原文/记忆/原图接续及草稿保护。
`electron scripts/check-account-send.cjs` 使用隔离账号页面和原生右键事件，覆盖跨账号文字/图片发送、只同步草稿、目标草稿保护，以及视频入口和接口已移除。
测试不消耗真实账号额度；真实网页仍需要实际使用验证。

## 按聊天图片顺序重新导入

右键发送按钮，选择目标账号下的“读取聊天图片，按顺序重新导入…”。
预览可以读取来源输入框、最近含图消息或已加载的聊天图片；编号代表导入顺序，可以前移、后移或移除。
点击“按顺序重新导入到输入框”，工作站会逐张重新上传，确认当前图片出现后才处理下一张。
来源页面可读取的图片会保存为本地资产；网页只给缩略图时无法保证原图分辨率。
目标已有草稿或图片时停止，避免覆盖。某张图片不能读取或上传时报告失败，不发送文字。
顶部快捷预览是资产快捷入口，尚未导入来源聊天框的图片不属于聊天图片。
