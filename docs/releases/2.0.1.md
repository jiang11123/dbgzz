# 豆包工作站 2.0.1：输入区菜单向上展开

发布日期：2026-10-22。[使用教程](../user-guide.md) · [更新日志](../../CHANGELOG.md)。

## 修复内容

发送账号、图片比例、视频比例统一改成向上展开的自定义菜单，与视频模型菜单保持一致，避免 Windows 原生下拉框朝下展开并遮挡输入区。

选项和参数含义保持不变。菜单支持方向键、Home/End、Escape、点击外部关闭以及选中后的焦点恢复；账号较多时可滚动选项。

## 验证与范围

- 主进程与界面类型检查、生产构建及完整自动化测试。
- 隔离 Electron 界面验证：日间/夜间下四类菜单均在按钮上方展开，选项切换、键盘操作、Escape、外部点击关闭通过。
- Windows x64 安装包及打包版本检查。

本次仅修复工作站聊天输入区的选择菜单，不改变内嵌豆包网站的控件行为。2.0.0 的能力边界及已知限制仍适用，线上账号生成流程本轮未重新验收。

## 下载升级

下载 Release 中的 `dbgzz-Setup-2.0.1-x64.exe`，可使用 `SHA256SUMS-2.0.1.txt` 核对文件。退出工作站、备份本地数据后运行安装包。安装包未签名，旧版本记录和附件保留。
