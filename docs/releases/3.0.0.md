# 豆奶画布 v3.0.0

产品由“豆包工作站”更名为“豆奶画布”，采用本地 AI 画布承载文字、图片、视频与素材创作，并保留豆包多账号调用。非豆包或 BeefTV 官方产品。

## 本次变化

- 应用、安装程序、启动页与界面 Logo 使用“豆奶画布”和奶蛙老师原图。
- 原始文字、图片、视频节点可选择豆包账号。
- 独立豆包文字、图片、视频节点默认隐藏，可在添加豆包账号附近开启“显示独立豆包节点”；设置会保存。
- Windows 正式安装版启动时及每 15 分钟检查 GitHub 新版本，提供下载进度、更新包校验及保存工作区后的安装流程。
- 更新源码、使用教程、发布步骤和第三方来源声明；保留历史版本与更新记录。

## 下载与升级

普通用户下载 `dounai-canvas-Setup-3.0.0-x64.exe`。`.blockmap` 与 `latest.yml` 是自动更新文件，无需手动打开。`SHA256SUMS-3.0.0.txt` 用于核对附件。

旧版先退出应用并备份用户数据，再覆盖安装。内部应用标识及 `doubao-video-workspace` 数据目录保持不变。此前没有自动更新功能的用户，需要先手动安装本版本。

## 验证与限制

本轮会核对类型检查、相关测试、生产构建和安装包内的版本、组件、更新元数据及哈希。实际新旧版本覆盖安装、账号登录状态保留和所有真实生成组合，需要在独立环境及用户备份后验收；构建通过不代表这些已全部通过。

更新依赖 GitHub 网络连接，仅对运行中的正式安装版检查；开发版及解压版不自动覆盖自身。生成能力受登录状态、额度、验证码、网页结构和所配上游影响。Grok 图片编辑仍取决于上游权限。Dola 2.0.3 修复版保留为历史分支，不将其能力视为 3.0 已验收能力。

许可和修改来源见 [NOTICE](../../NOTICE.md)。安装包目前无发布者代码签名。
