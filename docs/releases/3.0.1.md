# 豆奶画布 3.0.1 发布说明

## 更新摘要

本版本主要针对多账号使用体验进行针对性修复：
**修复添加或扫码登录豆包账号后，底栏模型下拉框没有自动刷新、必须退出重启应用才能看到的 Bug。**

## 详细变更

### 1. 账号变动实时同步
- 修复添加账号、扫码成功登录或修改账号后，主进程同步漏传 `hostBaseUrl` 导致通道未实时入库的问题。
- 主进程在账号创建、扫码成功、重命名、排序和删除后，统一广播 `workspace:model-config-updated` 与 `workspace:changed` 事件。

### 2. 前端配置热加载与静默重载
- 在 Preload 中向渲染进程派发自定义事件，前端 `WorkspaceBootstrapHydrator` 监听到通知后静默重新拉取后端最新模型配置，在不误写反向持久化的前提下完成内存与 Store 更新。
- 底栏模型下拉菜单（ModelPicker）在用户点击展开时，主动静默校验最新配置，确保新添加的账号模型能够第一时间呈现在列表中，无需手动刷新或重启应用。

---

## 升级方式

### 已安装 3.0.0 客户端的用户
- 启动客户端后，应用会自动后台检测更新并弹出提示，在左下角点击即可一键下载并自动升级至 3.0.1。
- 升级过程会自动保留原有的账号、画布和项目数据。
