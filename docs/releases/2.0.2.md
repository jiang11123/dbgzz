# 豆包工作站 2.0.2：奶蛙老师头像 Logo

发布日期：2026-10-22。[使用教程](../user-guide.md) · [更新日志](../../CHANGELOG.md)。

## 更新内容

- 使用用户提供的奶蛙老师人物图制作头像版 Logo。
- 更新工作站左上角、网页图标和仓库首页展示。
- 更新 Windows 应用、快捷方式、安装和卸载程序图标。
- 加入多尺寸图标资源和 `npm run build:icons` 重建命令。

## 下载升级

下载 Release 的 `dbgzz-Setup-2.0.2-x64.exe`，使用 `SHA256SUMS-2.0.2.txt` 核对文件。退出旧版并备份数据后安装。原有功能与历史记录保留。

如果覆盖安装后快捷方式仍显示旧图标，可先运行新版程序确认图标，再删除旧快捷方式并从开始菜单重新创建；Windows 可能缓存旧图标。
