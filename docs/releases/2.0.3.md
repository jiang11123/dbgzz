# 豆包工作站 v2.0.3 · Dola 修复验证版

本版本已正式发布，基于 2.0.2 修复 Dola 入口及统一文字聊天接入。2.0.2 和历史发布继续保留。

## 变更

- 恢复添加账号时的“豆包（国内版）/ Dola（国际版）”选择及独立登录会话。
- Dola 可在现有统一聊天窗口中选择发送账号，沿用消息显示和历史会话。
- 豆包保留原 HTTP 实现；Dola 通过站点原生发送流程提交消息。
- 修正切换账号后复用旧远端会话编号的问题，防止同账号并发驱动输入框、覆盖未发送草稿、失败后重复提交及将截断回复视为成功。
- 修正 Dola 回复被标注为豆包的问题。

## 验证结果与限制

- 类型检查通过，203 项自动化测试通过。
- 隔离 HTTPS 测试站点下，Electron 实际界面添加账号、发送账号选择、消息发送与回复显示、多轮上下文和账号隔离验证通过。
- 最终程序启动、原生 SQLite 模块加载、Dola 账号保存及平台选择检查通过。
- **真实 Dola 发送测试返回“当前网络所在地区不可用”，未取得真实模型回复。本版本尚未通过真实 Dola 账号验收。** 测试站点结果不能作为真实模型可用的证明。
- Dola 图片、视频、附件及深度思考控制尚未接入。本地 OpenAI 兼容 API 仍使用豆包账号；国内豆包原有媒体功能保留。

## 下载与使用

- `dbgzz-Setup-2.0.3-x64.exe`：Windows x64 安装包。升级前退出程序并备份完整用户数据目录及下载文件。
- `dbgzz-2.0.3-dola-portable-x64.zip`：解压后双击 `启动2.0.cmd`，使用独立的“数据”目录，不共用已安装版本的数据库。网关端口 8789、画布桥接端口 3220。
- `SHA256SUMS-2.0.3.txt`：上述发布附件的 SHA-256 校验值。

添加账号时选择 Dola，在账号页面完成登录，然后返回统一聊天，在“发送账号”中选择该账号。若出现地区限制或登录验证，请先在账号页面处理。

不包含作者的账号数据、登录会话或素材。完整验证范围见 [验证记录](../dola-2.0-verification.md)。
