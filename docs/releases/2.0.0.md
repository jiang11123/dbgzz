# 豆包工作站 2.0.0

发布日期：2026-10-22。本次在原仓库延续 0.1.2 的提交历史，旧版本及 Release 保留。

## 下载与教程

- Windows x64 安装包：`dbgzz-Setup-2.0.0-x64.exe`。
- SHA-256 校验：`SHA256SUMS-2.0.0.txt`。
- [完整教程](../user-guide.md)：安装、登录、文字/图片/视频、下载目录、API、备份升级与排障。
- [完整更新记录](../../CHANGELOG.md)。

## 主要变化

- 统一聊天与独立账号页面双模式，流式 Markdown、历史会话及深度思考。
- 账号池自动调度、本机文字/图片 API、网关配置、健康状态和日志。
- 图片/视频生成、参考图片、模型/比例/时长选择、同会话确认与补充。
- 多账号并发隔离、会话结果同步、媒体保存和视频尾帧提取。
- 日夜主题、新布局与下载目录设置。
- 移除 Video2X 超分及旧字段，补充教程和更新记录。

## 发布验证

执行类型检查、生产构建、自动化测试、Windows 安装包构建及打包内容检查；实际结果见 GitHub Release 正文。

自动化检查不能代替线上账号的全部真实操作。本轮发布不宣称覆盖所有模型、账号权限及旧数据组合的端到端验收。升级后请先验证自己使用的流程。

## 已知限制

- 安装包未签名，Windows 可能显示发布者未知。
- HTTP 视频尚未接入运行时回调，请通过桌面视频模式生成。
- 模型菜单为固定选项，可用模型、时长和额度以豆包账号页面为准。
- 网页结构、验证码、限流、网络及链接有效期可能影响运行。
- 旧画布桥接仅监听本机 `3219`，尚未统一 API Key 鉴权，不要映射到公网。
- 没有自动更新功能，请从原仓库 Release 手动下载。

## 升级提醒

退出程序，备份完整用户数据目录及下载文件，再运行安装包。部分迁移会删除旧额度/时长及超分相关结构，不要先清除旧数据；回退需要升级前完整备份。
