# Dola 2.0 修复验证版

基线：`v2.0.2`（9080db3）；修复版本：2.0.3。独立分支 `fix/dola-2.0`，不包含本机 3.0 工作目录的未提交修改。

## 修改范围

- 添加账号时恢复“豆包 / Dola”选择，Dola 使用独立浏览器会话。
- 统一聊天保留现有窗口、IPC、账号池、消息存储和历史记录，按账号平台选择发送实现。
- 豆包保留原 HTTP 发送方式；Dola 使用网站原生输入框发送，观察对应请求是否完整结束，并只读取本次新消息之后的回复。
- 防止账号切换复用其他账号的远端会话、防止同账号并发驱动输入框、防止覆盖草稿及错误后重复发送。
- Dola 登录状态使用会话 Cookie 是否存在判断，不再将登录页或地区限制页加载成功视为已经登录。

## 已验证

- `npm run typecheck`
- `npm test`：203 项通过。
- `npm run test:dola:integration`：真实 Electron 程序和统一聊天 UI，远端 Dola 页面使用隔离 HTTPS 测试站点。
- 测试站点验证了：界面添加 Dola、独立 Session、发送账号选择、发送到回复显示、多轮上下文、不同账号历史隔离和不支持的媒体请求不会切换到豆包。
- 独立安装依赖后重新生成安装包，最终程序启动、原生 SQLite 加载、Dola 账号保存和平台选择检查通过。
- 使用最终程序通过统一聊天实际尝试发送测试口令，返回“Dola 当前网络所在地区不可用，请在账号页确认网络”，没有取得真实模型回复。

## 验证边界

- 实际 Dola 访问在本机隔离探测中跳转到 `https://www.dola.com/security/region-restricted?source=1`。未取得真实 Dola 模型回复，因此这仍是待真实账号验收的修复验证版。
- Dola 图片、视频、附件及深度思考控制尚未接入，相关请求明确报错；国内豆包原有功能保留。
- 本次没有覆盖已安装的 3.0，也没有修改其账号、会话或数据库。
- `DOUBAO_USER_DATA_DIR` 可以为修复版指定独立的数据目录，避免与已安装版本共用数据库。

## 证据

本地 `verification/` 目录保留类型检查、回归、构建、Electron 集成测试、打包和启动验证日志，以及截图和 JSON 报告。测试站点截图不能作为真实 Dola 模型成功回复的证明。
