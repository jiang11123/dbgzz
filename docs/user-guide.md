# 豆奶画布 3.0 使用教程

[返回首页](../README.md) · [下载最新版](https://github.com/jiang11123/dbgzz/releases/latest) · [更新记录](../CHANGELOG.md)

## 安装与账号

下载安装包 `dounai-canvas-Setup-3.0.0-x64.exe`，运行后从桌面打开“豆奶画布”。首次启动会初始化本地工作区。

点击主页左上角的豆包账号按钮，在弹层中选择“添加豆包账号（扫码）”。按打开的豆包页面提示完成登录。可添加多个账号；各账号使用独立会话。验证码需要用户在账号窗口中手动处理。

账号管理中可以刷新状态和删除账号。忙碌账号不能删除，并至少保留一个账号。状态在线仅表示当前检测结果，不代表该账号的所有生成额度或模型均可用。

## 在原始节点调用豆包账号

1. 从首页新建画布，或打开已有项目。
2. 点击画布底部的 `+`，添加“文本”“图片”或“视频”节点。
3. 在节点模型选择器中选择“豆包账号：账号名称”。按图片/视频类型选择对应的豆包网页模型、比例及其他可用参数。
4. 输入提示词；需要参考素材时，将已有图片等节点连接到当前节点，再提交生成。
5. 查看任务状态与结果。需要回复或确认时，在界面中补充信息；出现验证码时先处理账号窗口。

选择豆包账号是使用该账号的网页生成能力；选择自定义 API 模型则使用对应渠道。豆包账号不会自动替代已配置的 API 默认模型。

## 显示独立豆包节点

独立“豆包文字”“豆包图片”“豆包视频”默认不出现在创建菜单。打开主页的豆包账号管理，在“添加豆包账号”附近开启“显示独立豆包节点”。

开启后，新建菜单、右键创建和拖出连线的创建菜单会显示这三类节点；关闭后恢复原始节点菜单。开关会记住当前工作区用户的选择，已有画布内容保留。原始节点中的豆包账号选项始终可用。

## API 模型

在侧栏“模型配置”中添加自己的渠道、密钥与模型协议，并按需要选择默认模型。生成可能产生对应服务的费用。读取到模型列表不等于该上游具备生成权限，错误时应检查具体渠道和账号。

## 更新软件

正式安装版启动时和每 15 分钟检查 GitHub 稳定版。发现新版本后，点击左下角的更新入口下载安装。

下载包校验通过后，软件先保存工作区，再启动安装。保存失败或豆包任务、下载未结束时会暂停安装。开发版和直接解压运行的版本不自动覆盖自身，需使用正式安装版。

仅在本地修改代码不会向用户推送更新；发布者需上传更高版本的安装包及对应更新元数据。旧版用户需先手动安装一次带更新功能的版本。

## 备份与升级

关闭应用，备份 `%APPDATA%\doubao-video-workspace` 整个目录以及自行设置的下载目录。数据目录包含项目数据库、模型设置和登录会话，只在可信位置保管，不上传 GitHub 或公开分享。

“豆奶画布”继承原软件的数据目录。运行新版安装包覆盖安装，不要先删除旧数据。生成前后请定期检查重要项目和输出文件。跨版本覆盖安装与数据恢复仍建议在备份后自行确认。

## 故障与反馈

- 无豆包账号选项：确认软件和网关已启动，刷新账号列表并检查登录状态。
- 生成失败：记录任务错误、所选模型和输入类型；检查额度、网络及验证码。
- 检查更新失败：确认可以连接 GitHub，稍后重试或从 Releases 手动下载。
- 反馈时附版本号、系统、复现步骤和脱敏截图，避免附登录会话、密钥或完整数据目录。

历史版本操作见 [2.0 教程归档](archive/2.0-user-guide.md)。
