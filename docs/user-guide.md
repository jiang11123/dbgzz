# 豆包工作站 2.0 使用教程

[返回首页](../README.md) · [更新记录](../CHANGELOG.md) · [下载安装包](https://github.com/jiang11123/dbgzz/releases)

## 安装与首次启动

适用 Windows x64。普通用户只需安装包，无需 Node.js、Python 或开发工具。

1. 从 Releases 下载 `dbgzz-Setup-2.0.2-x64.exe`，运行后选择安装目录。
2. 从桌面打开“豆包工作站”。目前安装包未签名，如显示发布者未知，请确认文件来自本仓库 Release。
3. 首次安装会初始化默认账号槽位，槽位不代表已经登录的真实账号。
4. 点击顶部账号标签，在豆包页面完成登录、扫码或验证码。
5. 切回“网关模式”，先发送一句简单文字，确认账号能实际回复。

只看到账号状态点或 API 健康检查成功，不能代替真实回复验证。

## 两种模式

| 模式 | 主要用途 |
| --- | --- |
| 网关模式 | 统一聊天、图片/视频生成、历史会话、结果保存 |
| 账号模式 | 直接操作某个账号的豆包网页，登录、完成验证、查看站点真实状态 |

点击顶部模式按钮切换。点击账号标签会进入对应账号页面，需要统一聊天时再切回网关模式。“网关模式”聊天区用于直接操作；“API 网关”用于其他本机客户端接入，两者入口不同。

## 添加与管理账号

1. 点击“添加账号”，填写名称和备注并创建。
2. 在打开的独立豆包页面中自行登录。
3. “设置 → 账号管理”支持改名、拖动调整顺序、设置快捷键和删除。
4. 聊天区“发送账号”可以选择自动调度或指定账号。

每个账号使用独立会话。自动调度会考虑忙碌、冷却、额度和登录状态，不代表增加账号额度。遇到掉线或验证码时，先进入相应账号页面处理。删除账号前确认不再需要相关配置。

## 文字聊天与历史会话

1. 切回网关模式，左侧“会话”区域点击 `+`，或直接开始输入。
2. Enter 发送，Shift+Enter 换行。需要时开启“深度思考”。
3. 回复支持流式 Markdown、代码块、列表与表格。
4. 继续追问时点击原会话，不要每次都新建；切换会话后先确认标题和消息内容。
5. 输入框旁 `+` 可添加文件。具体文件类型的处理能力以豆包实际支持为准。

## 图片生成与参考图

1. 开启“图片模式”，选择比例，例如 `1:1` 或 `16:9`。
2. 输入画面描述，例如：`一只坐在窗边的橘猫，暖色插画，背景简洁。`
3. 需要参考图时，用输入框旁的 `+` 添加图片，或从顶部图片资产栏加入。
4. 检查待发送区出现正确附件预览，再点击“生成图片”。附件旁 `×` 可移除本次附件。
5. 结果出现后，用卡片下载按钮保存；也可按卡片提供的操作将图片继续用作参考。

图片放进素材库不等于已经发送给豆包，发送前应检查当前会话的附件预览。

## 视频生成与确认

1. 开启“视频模式”，选择模型、比例及视频时长。
2. 输入主体、动作、镜头与风格；需要参考图片时先加入附件。
3. 点击“生成视频”。生成可能需要数分钟，具体取决于排队和账号情况。
4. 如果豆包要求确认参数，请在**当前会话**点击确认，或输入确认/修改要求并发送补充文字。
5. 等待结果卡片后下载视频；需要衔接下一段时，可使用视频尾帧下载功能。

任务进行中可以补充文字。不要反复创建新任务来代替确认。长时间无进展时，进入对应账号页面查看验证、额度或任务提示。

模型选项是固定列表，不保证每个账号均可使用。时长滑块是请求参数，实际可用模型、长度、分辨率与下载版本以豆包返回为准。本版没有 Video2X 超分功能。

## 下载设置

1. 打开“设置 → 下载设置”。
2. 在“视频保存与监听目录”点击“选择目录”，选择有写入权限的文件夹。
3. 使用“打开目录”查看保存位置。聊天结果卡片支持图片/视频下载，保存后可通过提示中的“打开下载位置”查看文件。
4. 账号页面中的视频还可以通过右键菜单使用可用的下载功能。

程序尝试获取可用的高清/无水印源，不保证所有来源均成功。建议及时保存结果，远程链接可能过期。

## 日间与夜间主题

使用顶部主题按钮切换，工作站会记住选择并同步至其他工作站面板。内嵌豆包网页的主题由站点自身控制。

## 本地 API 接入

保持工作站运行且至少一个账号可正常回复，打开“网关设置”，检查是否“运行中”，复制接口地址和 API Key。

| 客户端配置 | 填写内容 |
| --- | --- |
| 服务类型 | OpenAI 兼容 |
| Base URL | 默认 `http://127.0.0.1:8788/v1`，以界面实际值为准 |
| API Key | 从网关设置复制，首次运行自动生成 |
| 文字模型 | `doubao`，深度思考使用 `doubao-think` |

先使用“网关设置 → 试一句”，再在目标客户端发送消息。密钥留空保存后也会重新生成，请复制实际显示值。模型别名不等于额外官方模型权限。

### PowerShell 示例

密钥只在本机输入，不要写入公开代码或截图：

```powershell
$baseUrl = 'http://127.0.0.1:8788/v1'
$secureKey = Read-Host '粘贴网关设置中的 API Key' -AsSecureString
$gatewayKey = [System.Net.NetworkCredential]::new('', $secureKey).Password
$headers = @{ Authorization = "Bearer $gatewayKey" }

# 查询模型，仅验证端口和鉴权
Invoke-RestMethod -Uri "$baseUrl/models" -Headers $headers

# 真实文字请求，会使用已登录的账号
$body = @{
    model = 'doubao'
    messages = @(@{ role = 'user'; content = '你好，请简单介绍一下你自己。' })
    stream = $false
} | ConvertTo-Json -Depth 6
Invoke-RestMethod -Uri "$baseUrl/chat/completions" -Method Post `
    -Headers $headers -ContentType 'application/json; charset=utf-8' `
    -Body ([System.Text.Encoding]::UTF8.GetBytes($body))

Remove-Variable gatewayKey, secureKey, headers
```

文字接口支持 `stream: true` 的 SSE 返回。图片接口是 `POST /v1/images/generations`，不保证所有 OpenAI 参数兼容。

HTTP 视频路由虽然存在，但本版尚未为 HTTP 网关接入实际视频回调，会返回未启用提示；视频生成请使用桌面“视频模式”。

网关默认本机端口 `8788`，旧画布桥接使用本机端口 `3219`。两者不同。旧桥接尚未统一 API Key 鉴权，请勿通过代理或端口映射公开。监听地址为 `127.0.0.1`，其他电脑不能直接连接。

## 备份与升级

数据保存在 Electron 用户数据目录。Windows 通常位于 `%APPDATA%\doubao-video-workspace` 或 `%APPDATA%\豆包工作站`，以实际运行版本为准。

1. 退出程序，在资源管理器地址栏输入 `%APPDATA%`。
2. 找到对应目录，里面通常有 `workspace-data\workspace.db`、账号会话分区、图片资产等。
3. 将**整个用户数据目录**复制到私人备份位置。只复制数据库不能完整保留会话和素材。
4. 另外备份自己选择的下载目录，它可能位于用户数据目录之外。
5. 运行新版安装包，沿用原安装位置，不要清除旧数据。
6. 升级后核对账号、素材、会话记录、下载目录，再测试自己需要的文字和媒体流程。

部分旧字段迁移会自动生成数据库备份，但不能代替完整备份。新版移除了旧的额度/时长字段及超分相关结构。回退时，应退出程序，使用升级前完整备份配合旧版程序。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 没有可用账号 / 503 | 打开账号页确认登录、验证和额度，检查冷却状态，必要时换用可用账号 |
| 710022004 / 人机验证 | 在对应账号页面人工完成验证后再试 |
| 访问频繁 / 额度耗尽 | 等待恢复或额度重置，避免连续重发 |
| 视频一直等确认 | 在原会话发送确认/补充，并检查对应账号页 |
| 模型或时长不符合预期 | 检查豆包实际模型权限与任务参数，账号能力可能不同 |
| 素材不存在 / 附件失败 | 检查本地文件是否移动或删除，重新添加并确认预览 |
| 下载失败 | 检查目录权限、网络和原账号登录，链接可能已过期 |
| API 401 | 重新复制实际密钥，检查 `Authorization: Bearer ...` |
| API 无法连接 | 确认工作站运行、网关启用及端口正确；仅支持本机连接 |
| 端口占用 | 退出重复程序，或修改网关端口并同步更新客户端地址 |
| 升级后数据不见 | 核对 Windows 用户和数据目录，不要覆盖原目录，必要时使用私人备份 |

仍有问题请到 [Issues](https://github.com/jiang11123/dbgzz/issues)，提供版本、Windows 版本、步骤、错误文本和脱敏截图。不要上传密码、Cookie、API Key、数据库或会话目录。
