BeefTV Windows media tools

This directory contains the pinned BtbN FFmpeg and FFprobe GPL static build.
See manifest.json for the exact version, binary checksums, original upstream
archive, build recipe, and the release containing corresponding source files
and BUILD.md instructions.

LICENSE.txt is the unmodified upstream GPL license. LICENSE is an identical
copy retained for compatibility with previously released BeefTV updaters.
This README describes the BeefTV package; it is not an upstream BtbN file.

FFmpeg and its dependencies retain their own licenses. BeefTV's source-
available restrictions do not override those third-party licenses.
