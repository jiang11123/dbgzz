## 内置助手与权限

当前画布读取、选择上下文、素材引用、批量节点与连线、后续追改均核对真实工具和持久化状态。拒绝生成提议不产生媒体任务；过期提议、重复确认和保存屏障另外核对原操作关联。新会话、历史切换、停止回答及应用正常退出重开均由真实界面验收。重启前后的三个已有画布节点与连线摘要一致，86 份资源保留，已有会话权限及 Skill pin 保留；重启后的新对话单独登记，不能要求整个会话列表不变。

内置 Pi 的只读、当前画布、完全访问分别测试。完全访问实际修改同一用户的另一个画布；当前画布权限实际拒绝跨画布写入。只读模型拒绝写入，正式业务 handler 的确定性负例另证写入不能绕过权限；不声称只读原生轮次尝试过 HTTP 写入。身份、素材归属、版本冲突和余额检查继续适用。停止与恢复不得偷偷升权，跨画布撤销不得覆盖后来的手动改动。

Skill 经正式界面安装和选择，真实 Markdown 版本修改、重启 pin、卸载与重新导入分别验证。辅助文本和 scripts 目录文件可读，不等于允许执行脚本。未选择 Skill 的轮次在 skill_get 前置检查被拒绝，不把它称为已执行 skill.file；越界文件、错误摘要、版本混搭和旧 pin 拒绝通过正式管理接口另行检查，接口测试不冒充界面操作。

真实视频检查使用连续 video 载荷，并人工播放原始 3 秒参考视频核对翻页方向、桌面布局和窗光。真实音频检查记录 audio 载荷与指定区间，包含通过正式界面添加音频及运行中补充。媒体版本经过校验，文件名、抽帧或音量数据不当作模型听过或看过。

仅 durable_resume、budget、scope_isolation、host_recovery、conflict_undo 使用允许的确定性故障检查。当前源码的正式 Durable/SQLite、默认 HTTP 流、宿主终止、请求和工具预算耗尽、停止后的零后续写入均通过；官方 owner/persisted counter 23/23 无跳过、Go 19 个顶层与 21 个子例无跳过、流空闲与重试 15 个例通过。支持的 SSE 格式按内容进展续读，超过 95 秒总时长可继续；静默异常有空闲检测与有限重试。该保护覆盖已识别的 completions、responses、Anthropic SSE；原生 Gemini、未知协议及非 SSE 保持供应商原有行为，不能据此承诺所有上游永不失败。
