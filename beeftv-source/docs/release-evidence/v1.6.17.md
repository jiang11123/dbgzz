# v1.6.17 真实客户端验收

2026-10-01，候选源码 `c39d2b2`，macOS arm64 正式应用路径中的 v1.6.17 本地构建。六条路径各两轮，12/12 成功；额外开启声音生成一次成功。机器可读任务、账单、产物哈希、参数和源码摘要见 [验收回执](./v1.6.17.json)。这些是发布前候选构建验收，正式分发包和更新源须在发布后单独读回。

## 原因与修复

群内 v1.6.15 的 `table tasks has no column named failure_diagnostics` 发生在本地保存任务时。旧预览分支占用了迁移编号 3 至 6，使正式迁移按最大编号跳过补列；本机真实数据库具有该缺列状态，隔离的 v3/v6 数据库也复现了同样失败。不能据此断言报告者安装过哪条预览分支。

当前迁移核对实际列并在事务中补齐，已有迁移记录、项目、任务保留。本地任务写入失败现在返回 `local_storage_failed`，说明尚未提交生成；不会再显示“模型不接受当前参数”。容量不足继续保留配额分类。BeefAPI Seedance 新目录和旧保存配置恢复声音开关，明确发送关闭声音的参数；第三方端点配置不受内置合同修复影响。
