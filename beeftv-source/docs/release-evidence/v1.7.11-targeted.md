## 故障与修复

群反馈是图片上游及下载均成功，绑定时显示“原任务节点已删除”，但截图中节点仍可见。本地测试复现的是新增目标尚未保存，画布保存冲突被忽略后开始生成，后端绑定看不到该节点；没有把用户主动删节点认定为群故障根因，也未在原反馈人的 Windows 机器复现。

图片提交前必须保存目标，保存失败不提交付费请求。已经成功的任务若未放入画布，保留原结果并允许查询/重新加载，不触发再次生成。真正删除的节点不重建；多图结果只更新对应目标，保留用户当前编辑及兄弟节点。账号或画布切换后，旧请求停止前端消费。恢复过程中持续禁止重复生成。
