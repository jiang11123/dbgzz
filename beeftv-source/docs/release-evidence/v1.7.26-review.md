## 参考图故障复现

用户原始素材不在诊断包内。使用自有 PNG 复现四图尺寸和字节数：3136×1344（6,031,821 与 5,969,853 字节），340×340（168,102 与 95,643 字节）。CF→COS 基线、三轮重复上传、首图入站停顿 45 秒均通过，独立 HEAD/MD5 一致且临时对象已删除。控制制造的 COS BadDigest 复现存储失败路径，不代表已经找回历史故障的具体 COS 原因。最终 Worker 真实拒绝探针从 Mac 经生产 CF 到 COS 返回脱敏状态和 request id，确认没有遗留对象。

服务端覆盖同键同字节重试、回执丢失后的 HEAD/MD5 续接、永久错误不重试、脱敏和更早未知尝试的保护。Worker 32 项通过，覆盖错误正文停顿和取消挂起时释放名额。客户端覆盖受管网关未提交证明、外部跳转/缺失证明负例、只发送一次、主动重试与禁止自动重发。

这验证上传与失败恢复，没有重放客户原始提示词或调用模型，也没有重新提交客户原任务。
