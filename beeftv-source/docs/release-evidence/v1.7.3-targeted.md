## 接入与凭据专项

在整合后的 Vite 页面与真实本地 Go 后端上使用隔离工作区和合成 Key：

1. 读取目录失败时显示连接失败及可手动添加提示，没有保存空渠道。
2. 恢复本地模拟服务后读取目录，选择文本/图片模型，保存并刷新页面，渠道、模型及默认选择保留。
3. 在高级模型设置中明确确认生成测试，经生产任务入口等待模拟上游文本完成后显示「测试通过」。此处不是付费供应商回执。
4. 浏览器持久缓存不含合成 Key；配置文件及 `.bak` 都是 `schemaVersion: 2` 密文。
5. 工作区专项验证明文旧配置迁移、重复读写、携带 `.settings-key` 的配置副本恢复、缺密钥拒绝读取/覆盖且不生成替代密钥。
6. 启动屏障浏览器回归验证：session 已准备而 canonical 配置仍未返回时不渲染创作入口；读取失败显示重试，不暴露缺凭据生成入口、不自动保存。
