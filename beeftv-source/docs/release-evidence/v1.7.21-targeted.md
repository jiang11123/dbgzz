## 唯一新视频

冻结并提交候选后取得 `node scripts/verify-real-generation-release.mjs --fingerprint`。在最终候选原生客户端提交一次 `text-video`：`seedance-2.0-mini`、480p、16:9、4 秒，无参考素材。记录新本地 task、网关 task、provider request 与资源 ID，确认完整下载和保存、画布首帧、实际播放、解码、重开同一任务及文件大小和 SHA256。保留原任务和时间记录，不以旧结果重放替代新生成，不再追加付费生成。

执行前从当前报价获得 `pricePreflight.maxCostCNY`，核对账户余额和既有未结算预扣；`newBudgetCNY` 等于这一次实际预检的最大费用。这是提交的价格上限，不是另一个 50 元预算授权。报价未知或余量不足不提交。状态不确定先查询并恢复原任务；只能在最终结算后填写成功。`newSpentCNY` 等于唯一媒体账单的实际费用，`newPendingCNY=0`。

历史 `budgetCNY/spentCNY/pendingCNY` 继续为 null。`priorFinancialUncertainty` 保留 `status=unresolved`、`carriedFromVersion=v1.7.20`、`pendingCNY=null` 和 `docs/release-evidence/v1.7.20.json` 引用。前期诊断和旧测试证据保留各自实际版本、费用与执行来源，不计为本次候选的新视频。

- `ownerException`：`approvedBy=Ender`、`instruction=你跑一次生视频成功就可以了`、上述精确 scope、当前 `sourceDigest` 与本文件证据。
- `releaseAuthorization`：`scope=v1.7.21 only`、`additionalHumanReplyRequired=false`、当前 `sourceDigest` 与授权证据；`paidSubmissionLimit=1`。

- `cases` 恰好一项：`path=text-video`、`method=native`、`clientVersion=v1.7.21`、当前 `sourceDigest/executedSourceDigest`、模型、秒数、画质、比例；`taskId/gatewayTaskId/providerRequestId/resourceId/platform`、`createdAt/completedAt`、`freshSubmission=true`、`submissionCount=1`、`status=succeeded`、`billing=settled`、`billingMarket=enterprise`、实际 `costCNY/bytes/artifactSHA256` 与非空证据。`clientSubmitted/downloaded/saved/canvasVerified/canvasFirstFrame/mediaDecoded/mediaOpened/playbackVerified/reopened/noDuplicateSubmission` 均为真实验证的 true，`reopenedTaskId` 等于原 task ID。
- `billingAttempts` 恰好一项：实际账单 `id`、`kind=media`、`billing=settled`、与 case 相同的 `taskId/providerRequestId/executedSourceDigest/costCNY` 和结算证据。
- `review`：当前源码的 `result=approved`、`independent=true`、`reviewer/sourceDigest/evidence`。`upgrade` 保存真实 `preservedData=true` 与当前 `sourceDigest/evidence`。
- `verification`：`directAndBackupDelivery/signedURLRefresh/cancelAndStall/noDuplicateSubmission` 的 `method=test`，`localReleaseGate` 的 `method=local-script`，`ci` 的 `method=github-actions`；每项当前 `sourceDigest`、真实 `status=passed` 和非空证据。

脚本检查字段与版本绑定；发布人及独立 reviewer 仍需核对证据真实性。凭据、签名 URL 和私有提示词不得进入公开回执。
