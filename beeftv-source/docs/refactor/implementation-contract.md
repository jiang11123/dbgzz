## 目标边界

1. 人工 UI、内置 Agent、CLI/MCP 共用具体业务操作；身份/范围、operation ID、revision 与回执由后端校验。
2. SQLite 拥有已提交业务状态；前端仅拥有显示和明确的未提交编辑，不以缓存时间戳竞争最终事实。
3. 画布修改、资源引用、幂等记录与必要历史在一个事务内提交；文件与网络通过明确的暂存、恢复和补偿处理。
4. 任务意图、上游请求、文件交付与节点绑定分离。未知执行状态不盲目重新付费；原任务身份可恢复。
5. pi 管理模型会话、上下文与官方运行语义；Go 管理业务操作、确认、轮次归属、权限与实际变更回执。
6. 宿主进程生命周期由 runtime 管理，HTTP handler 只转换协议。
7. Provider 目录、Protocol 协议、Transport 出站与媒体传输分离；UI/Agent 使用同一有效能力合同。
8. 时间线统一渲染计划，原生与浏览器执行器采用同一内容语义。字幕/音轨缺失不能默认为完整成功。

## 核心验收

- 迁移：正式 v2/v3、测试 v3/v6/v8/v9 的真实结构夹具，保留项目/素材/任务/会话/操作记录和未知历史列；中断重试与未来版本拒绝。
- 并发：人工与 Agent 交错修改，冲突不覆盖；撤销不抹除后续编辑。
- 可靠性：提交前后、上游接单后、下载后、数据库提交前后故障注入；只能回放安全操作。
- Agent：官方 SDK 生命周期和隔离加载测试；真实模型闭环在另行明确预算后执行。
- 剪辑/备份：实际媒体时长/音轨/字幕及全新工作区导入验证，不以源码断言代替输出。
- 平台：macOS/Windows 真实升级、进程终止、媒体工具和文件保存；三平台签名更新源与打包回执。
- 性能：固定画布/任务规模登记基线，再设可执行阈值；不得虚构性能已改善。
- 发布：冻结候选后完整两轮六类真实生成、专项 Agent/迁移验收、独立 review；旧版回执不能换 sourceDigest 冒用。
