# 内置 Pi 权限与外部业务工具

本地实施合同，来源为本会话 Ender 确认：执行权限只管理内置 Pi；外部 Agent 通过 MCP / CLI 使用全部业务工具，其执行审批由外部 Agent 自己管理。所有入口继续执行业务自身的身份、归属、参数、余额及版本冲突校验。

## 产品行为

- 内置助手显示“只读 / 当前画布 / 完全访问”。旧记录及缺省模式保留当前画布，不静默提升权限；新选择按账号保存。运行中的模式由后端回合记录决定，补充消息、恢复或模型参数不能提升。
- 完全访问允许读取本用户工作区素材与画布、跨画布编辑。每个受影响画布在第一次写入前保存原文；撤销检查全部目标，任何一张被用户修改时不得部分恢复。
- 只读不执行画布编辑、渲染或生成提议。完全访问指 BeefTV 业务能力，不代表自动执行宿主机 shell。
- 外部连接只完成身份登记，不要求用户再次选择只读/读写或逐步确认业务操作。新连接完整访问；历史明确签发的只读凭据不能被代码更新悄悄提升，可重新连接签发新凭据。
- 外部工具可发现且可调用真实业务 API，复用已有 handler/service；不能把共享操作目录等同全部业务覆盖。CLI 提供通用操作调用与业务调用，MCP 使用同一目录和鉴权。
- 外部 Agent 不读取已有密钥、发行其他客户端凭据、控制内置宿主或更新器；这些不是创作工具。资源上传使用上传接口，不把任意本机路径交给后端。

## 必须验证

1. 内置只读拒绝写入及生成提议；普通画布模式拒绝跨画布写；完全访问对另一张 owned 画布读写成功，其他用户资源仍拒绝。
2. 权限入 Go 持久记录；进程重开、补充输入和重放不得改变权限。结束或撤销后不能继续写。
3. 同一轮跨画布修改结算成功；原子撤销恢复全部画布，手改任意目标后撤销整体拒绝。
4. 节点移动保留内容/参数；删除节点只清理相连边；移除连线不删除节点和素材。版本冲突与稳定操作 ID 去重有效。
5. 外部连接不出现执行权限选择；MCP / CLI 能发现并调用现有业务功能，无重复 UI 审批。
6. 外部业务目录与调用同源；拒绝伪造凭据、任意 URL/headers、未列入目录路由，以及敏感配置泄露。已撤销与历史只读凭据仍遵守原授权。
7. 真实无费用素材上传、业务编辑/查询与 MCP 握手通过；付费提交只做无费用 fixture，不调用真实收费渠道。
