## 已落地的边界

- 人工界面、Agent、CLI/MCP 复用后端业务操作与回执；Go 控制身份、确认、revision 和实际变更。旧 Agent 调度、自建 MCP 和未接线写入口已退场，历史数据保留。
- 官方 `@earendil-works/pi-coding-agent@0.87.1` 管理会话、模型循环与上下文；使用实际 SDK 和全控资源装配，宿主进程归 runtime 管理。
- SQLite 保存已提交项目、画布、素材和任务；前端保留明确草稿，以提交回执确认，不用缓存时间戳覆盖最终状态。
- 生成执行、供应商请求、资源入库、素材物化与节点绑定分开；恢复保留原任务身份，未知执行状态不盲目重新付费。旧上传匿名额度不猜测归属。
- Provider/Protocol/Transport 与统一素材传输分离；公共能力由模型目录表达，UI/Agent 使用同一合同。不是把所有模型硬套一份白名单，也不是无条件透传输入。
- 时间线共用渲染计划；剪辑、转写、深度任务有同一准入边界。项目切换、账号切换和迟到回调覆盖到实际上传、设置、节点编辑及媒体导入入口。
- 九个既有 IndexedDB store 协调首次初始化，普通读写并行；初始化失败保留真实错误。绘图代际草稿与 blob 回收保留未确认数据。
- 新领域依赖边界检查不允许倒向 `internal/app`。剩余 app 组合/端口及专用事务经独立复审保留，未按文件行数强行拆分。
