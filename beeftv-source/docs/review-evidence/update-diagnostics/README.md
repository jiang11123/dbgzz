# 更新失败诊断验收

本次补齐更新失败后的排查入口、更新日志导出和超时阶段说明。不改变更新渠道、准备期限、程序替换、回滚或工作区保存策略。

## 已验证

- Go：更新器、诊断域、桌面入口测试通过；本地工作区与托管模式的日志导出隔离测试通过。
- 日志：读取当前目录的两个轮转文件，限制读取大小，按时间筛选，仅保留允许的诊断字段。私有路径、代理地址、凭据及未知正文不会进入导出文件。缺失、非普通文件、超长错误行与截断均有覆盖。
- 重试：从已有解压错误进入真实安装入口，取消校验后记录校验阶段及零文件进度，未启动替换助手。
- 前端：类型检查、完整构建、33 项现有更新/诊断测试通过。
- 浏览器：390 与 1440 宽度、明暗主题下实际点击排查、打开文件夹及导出；收起侧栏的 Popover 入口可见可点，打开目录失败的提示留在弹窗内。共 5 个场景通过。
- 国内 Windows：原生执行 Windows 更新器测试二进制，62 项通过，1 项按条件跳过。测试在独立临时目录执行，完成后已清理。

## 验证限制

浏览器截图使用确定性夹具，模拟更新失败及桌面打开目录绑定，未替代新安装包的原生 UI 验收。Windows 测试覆盖原生更新器，不等于本次改动的完整正式安装包验收。此前已完成官方 v1.7.20 到 v1.7.23 的国内直连完整更新，但未复现客户超时，不能据此断言其根因已修复。

合并前仍需项目约定的用户可见功能交叉 review；发布状态单独核验。
