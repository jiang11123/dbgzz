# Quaternius Standard male actor model

Source: [Universal Base Characters — Standard (free)](https://quaternius.itch.io/universal-base-characters), `Base Characters/Godot - UE/Superhero_Male_FullBody.gltf` and `.bin`.

Creator: Quaternius. The Standard package includes `License_Standard.txt`, which dedicates the models to [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Commercial use, modification, and redistribution are permitted.

The local `quaternius-standard-male.glb` was converted from that free package using `web/scripts/prepare-director-quaternius.mjs`. The conversion keeps the mesh, skin, and 65-joint skeleton, while dropping the source images and materials because BeefTV renders actors with its own material. The paid Source package is not included.
